# Survival Game

Un prototype très précoce d'un jeu 3D de survie et de construction jouable dans un navigateur. Pour l'instant, le projet affiche uniquement un petit diorama d'île low-poly : aucun gameplay n'est encore implémenté.

## Stack technique

- TypeScript
- Vite
- Babylon.js (`@babylonjs/core`)
- npm

## Prérequis

- Node.js 20.19+ ou Node.js 22.12+
- npm

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

Vite affiche alors l'adresse locale à ouvrir dans un navigateur.

## Construction

```bash
npm run build
```

La version prête à être déployée est générée dans `dist/`.
